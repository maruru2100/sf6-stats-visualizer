# SQL反映ガイド

リポジトリ内の SQL クエリを Metabase に反映し、グラフ化する手順と各クエリの解説です。

## 1. 基本的な反映手順

1. **SQLエディタを開く**: Metabase 右上の「+ 新規」→「SQLクエリ」を選択。
2. **SQLをコピー＆ペースト**: `analytics/queries/` 配下の `.sql` ファイルを貼り付けます。
3. **変数設定**: SQL内に `{{player_filter}}` 等がある場合、画面下部の変数設定でタイプを「フィールドフィルター」にし、対応するテーブルの列（`player_name` 等）を選択してください。
4. **実行と保存**: 右下の実行ボタン（▶）を押し、結果を確認して保存します。
